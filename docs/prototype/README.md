# CineB Webapp — Prototypes

Thư mục này dùng để lưu trữ các bản thiết kế mẫu giao diện (Prototypes), bản dựng tương tác HTML/CSS/JS nhanh, wireframes và mockups cho 4 màn hình của hệ thống CineB:

- **Màn 1:** Tổng quan (Dashboard)
- **Màn 2:** Đơn thuê (Orders & Lifecycle — bao gồm Modal Tạo đơn có thanh tìm kiếm & lọc danh mục thiết bị, quản lý Cọc giấy tờ, ngày thuê)
- **Màn 3:** Thiết bị (Asset & Profit — bao gồm nút Import Excel danh mục thiết bị)
- **Màn 4:** Lịch kế hoạch (Calendar Grid)

### Các file prototype:
- [`cineb-prototype.html`](./cineb-prototype.html): Bản prototype giao diện HTML/CSS/JS tương tác trực tiếp trên trình duyệt.
